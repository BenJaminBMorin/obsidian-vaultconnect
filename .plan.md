## Phase 2: Medium Effort Fixes

### 2.1 Replace `confirm()` with Obsidian Modals

**Files to modify:**
- `main.ts:1124,1165,1206` - Pull All, Push All, Force Sync confirmations
- `src/ui/SyncLogModal.ts:159` - Clear logs confirmation
- `src/ui/SettingsTab.ts:779,983` - Settings confirmations

**Approach:**
Create a reusable `ConfirmationModal` class:

```typescript
class ConfirmationModal extends Modal {
    private message: string;
    private onConfirm: () => void;

    constructor(app: App, message: string, onConfirm: () => void) {
        super(app);
        this.message = message;
        this.onConfirm = onConfirm;
    }

    onOpen() {
        const { contentEl } = this;
        contentEl.createEl('p', { text: this.message });

        new Setting(contentEl)
            .addButton(btn => btn
                .setButtonText('Cancel')
                .onClick(() => this.close()))
            .addButton(btn => btn
                .setButtonText('Confirm')
                .setCta()
                .onClick(() => {
                    this.onConfirm();
                    this.close();
                }));
    }

    onClose() {
        this.contentEl.empty();
    }
}
```

### 2.2 Fix Async/Await in Command Callbacks

**Files to modify:**
- `main.ts:415-478` - All command callbacks

**Current (incorrect):**
```typescript
this.addCommand({
    id: 'vaultconnect-connect',
    name: 'Connect',
    callback: () => this.connect()  // async method not awaited
});
```

**Fixed:**
```typescript
this.addCommand({
    id: 'vaultconnect-connect',
    name: 'Connect',
    callback: async () => {
        try {
            await this.connect();
        } catch (error) {
            console.error('Connect failed:', error);
            new Notice('Failed to connect');
        }
    }
});
```

### 2.3 Fix Sentence Case in UI Text

**Guidelines:**
- Capitalize only the first word and proper nouns
- Exception: Product names like "VaultConnect" keep their casing
- Button labels: Use sentence case ("Save settings" not "Save Settings")
- Error messages: Start with capital, end without period for notices

**Examples:**
- "Not connected to VaultConnect" ✓ (already correct)
- "Sync service not initialized" ✓ (already correct)
- "Pull All will download..." → "Pull all will download..."
- "Requesting authorization code..." → "Requesting authorization code..."

### 3.1 Replace Inline Styles with CSS Classes

**Files with most inline styles:**
- `src/ui/VaultSelectorModal.ts` - 45+ occurrences
- `src/ui/RecentActivityView.ts` - 50+ occurrences

- `src/ui/UploadProgressModal.ts`

**Approach:**
1. Create `styles.css` with all required classes
2. Use Obsidian's CSS variables where possible
3. Replace inline styles with `addClass()` calls

**Example transformation:**
```typescript
// Before
item.style.padding = '12px';
item.style.border = '1px solid var(--background-modifier-border)';
item.style.borderRadius = '4px';
item.style.cursor = 'pointer';

// After
item.addClass('vaultconnect-list-item');
```

**CSS:**
```css
.vaultconnect-list-item {
    padding: 12px;
    border: 1px solid var(--background-modifier-border);
    border-radius: 4px;
    cursor: pointer;
}
```

### 3.2 Fix `any` Type Usage

**Priority areas:**
1. Event handlers in services
2. API response types
3. Main plugin class properties

**Approach:**
1. Define proper interfaces for all event data
2. Type API responses explicitly
3. Use generics where appropriate
4. Use `unknown` + type guards for truly dynamic data

**Example fixes:**

```typescript
// Before
this.eventBus.on(EVENTS.SYNC_ERROR, (error: any) => {

// After
interface SyncErrorEvent {
    message: string;
    code?: string;
    details?: Record<string, unknown>;
}
this.eventBus.on(EVENTS.SYNC_ERROR, (error: SyncErrorEvent) => {
```
